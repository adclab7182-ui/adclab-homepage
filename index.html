Solution

에이디시랩의 열처리 솔루션

측정부터 보정까지 하나의 흐름으로 연결해, 열처리 공정의 온도를 정밀하게 관리합니다.

  1. 01

    측정 On-wafer Sensor

    웨이퍼 위 여러 지점의 온도를 직접 측정합니다.

  2. 02

    제어 Bake Control

    여러 구역의 히터를 동시에, 실시간으로 제어합니다.

  3. 03

    분석 Temp. Viewer

    수집한 데이터로 온도 분포와 장비 간 차이를 분석합니다.

  4. 04

    보정

    분석 결과를 제어에 반영해 장비 간 편차를 줄입니다.

Key Features

모니터링부터 비교·보정까지
하나의 프로그램으로

01

실시간 모니터링

Live Monitor
  • 센서 데이터를 실시간으로 수집해 표시
  • 웨이퍼 히트맵과 그래프로 온도 분포와 변화 추이 확인
  • 채널별 상세 데이터와 통신 데이터 로깅
02

오프라인 분석

Offline Analysis
  • 측정 세션 데이터 상세 분석
  • 히트맵·온도 분포 히스토그램·추이 추정 분석
  • 실제 공정 온도 변화 모사 기능
03

데이터 비교

Data Compare
  • 측정 세션 채널별 모든 편차 비교 후 통계화
  • 허용 오차 기준으로 채널별 정상/이상 자동 판정
  • 제어 파라미터 보정 방법 제시
04

채널 설정 · 교정

Channel Config · Calibration
  • 센서별 세부 관리 사항 설정
  • 채널별 경고·오류 판정 기준 온도 지정
  • 채널별 온도 보정값 관리
